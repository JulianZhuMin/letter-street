# 字母街 Letter's Street

A Cantonese letter-learning game for toddlers aged 2–4 (best in landscape). One page (`index.html`) with inline CSS and JS. Letter mascots stand on a suburban sidewalk; voice lines use edge-tts `zh-HK-HiuGaaiNeural` (rate −10%, pitch +8Hz) / `en-US-AnaNeural`.

Live: https://julianzhumin.github.io/letter-street/

Part of [星星學樂園 AstraGarten](https://julianzhumin.github.io/AstraGarten/).
