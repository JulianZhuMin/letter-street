# 字母街 Letter's Street

A Cantonese letter-learning game for toddlers aged 2–4 (best in landscape). One page (`index.html`) with inline CSS and JS. Letter mascots stand by the sidewalk (行人路邊); voice lines use edge-tts `zh-HK-HiuGaaiNeural` (rate −10%, pitch +8Hz) for Cantonese host, `en-US-AriaNeural` for English host questions, and `en-US-AnaNeural` (cartoon) for correct-answer "I am X" lines. Landscape tip is on-screen text on the start page only (no voice-over).

Live: https://julianzhumin.github.io/letter-street/

Part of [星星學樂園 AstraGarten](https://julianzhumin.github.io/AstraGarten/).
