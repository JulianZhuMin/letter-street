# 快樂字母 Happy Alphabet

A Cantonese letter-learning game for toddlers aged 2–4 (best in landscape). One page (`index.html`) with inline CSS and JS. Letter mascots stand by the sidewalk (行人路邊); voice lines use edge-tts `zh-HK-HiuGaaiNeural` (rate −10%, pitch +8Hz) for Cantonese host, `en-US-AriaNeural` for English host questions, and `en-US-AnaNeural` (cartoon) for group intros ("I am X") and correct-answer "Yeah, I am X" lines. Groups are 4+4+4+4+5+5. Landscape tip is on-screen text on the start page only (no voice-over).

Live: https://julianzhumin.github.io/letter-street/
